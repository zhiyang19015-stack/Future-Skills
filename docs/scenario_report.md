# Scenario regression report

Generated by `python scripts/scenario_report.py --write` from the data in this repository. Estimates under stated assumptions, not predictions.

Of 5 fictional people, the top 3 contains different occupations under slow and fast adoption for 1, and is in a different order for 3. No ranking is required to change: the model is not tuned to make it.
