# What it costs to run

Generated by `python scripts/cost_model.py --write` on 2026-11-14. Run it again to check every figure. Measured values come from the machine the script ran on, prices from the providers' own pages, and the rest are our assumptions, marked as such. People's time is not priced.

## Measured

- One full journey (the page, the six steps, one piece of simulated news, the team view): 24 requests, **3.92 processor seconds** and **221 KB** sent (gzip).
- Server memory at its peak: **192 MB**, against 1024 MB on the server priced below.
- Timed on: AMD64 Family 26 Model 96 Stepping 0, AuthenticAMD, Python 3.14.3. A rented core is assumed 3 times slower (assumption).
- One "Why this score?" request to the optional language model: about 952 tokens in and 350 out (the reply is cut off at 1500).

One server carries about 35.7 people working through the steps at the same moment, so a workshop of 40 sets the floor at 2 servers however few people use it in the month. The largest case sends 10.54 GB in the month, inside the 14000 GB included.

Not in the table: a domain name (optional), and upkeep of about 6 hours a quarter (the DOSM workbook, reviewing a new Economic Index release, checking links). The weekly data update runs by itself against free public sources. Without a language-model key the app costs the hosting line only.
